# Sortify

A premium interactive sorting algorithm visualizer built with React, Vite, Tailwind CSS and Framer Motion.

## Algorithms

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort
- Counting Sort
- Bucket Sort

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```
